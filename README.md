# Map Vote (3 Random Maps Fork) 🗺️
Allows you and your friends to vote for the next map to play, but adds a twist: **Every vote is limited to a selection of 3 randomly pulled maps!**

*Forked from the original [MapVote by Patrick](https://thunderstore.io/c/repo/p/Patrick/MapVote/).*

|Vote between 3 random maps ✅| Or randomly select one 🎲 | Vote again after each map 🗺️ |
